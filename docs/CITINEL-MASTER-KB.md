# PART 2 · THE LOCKED IDEA — "CITINEL — Autonomous Cyber SOC" (81/90 after 3 red-team cycles)

- **Tagline:** *The SOC that shows its evidence, obeys your policy, and beats the clock.*
- **One-breath pitch:** "An AI SOC that investigates every alert with cited evidence, acts only inside a policy you can read, and drafts your CERT-In report before the 6-hour clock runs out."

## 2.2 The locked 100–150-word template box (survived judge + tired-evaluator personas verbatim)
"[CITINEL] is an autonomous Cyber SOC that investigates every alert with cited evidence, acts only inside a policy humans can read, and beats India's regulatory clocks. Alerts from bank systems normalize to OCSF; Sigma rules catch known threats deterministically; Claude agents correlate the rest into a MITRE ATT&CK kill-chain narrative where every verdict cites the exact log line proving it. Response actions pass a per-action policy: enrichment runs automatically, host isolation runs with rollback, disabling a production account waits for one-click human approval. The pipeline treats all log content as untrusted data, so a poisoned log cannot hijack the AI. On confirmation, it drafts the CERT-In 6-hour report and DPDP breach artifacts for human sign-off. Built for cooperative banks that RBI requires to run a 24×7 SOC they cannot afford."

## 2.3 Target user & why-now
- **Primary persona:** IT head/CISO-equivalent of a cooperative bank or small NBFC. **Channel:** MSSPs + SEBI-mandated Market-SOC operators (B2B2X). Secondary skins: SEBI-regulated small entities, hospitals.
- **Pain:** C-Edge/RansomEXX took ~300 co-op banks offline in one 2024 attack; RBI mandates 24×7 C-SOC with 6-hr reporting; human SOC ₹1–2 cr/yr vs ₹25k–₹1L/month budgets; India breach cost record ₹220M (IBM 2025).
- **Why now (honest frame):** CERT-In 6-hr rule in force since Jun 2022; SEBI CSCRF SOC deadlines passed 2025; DPDP penalties (₹250cr + ₹200cr, stackable; 72-hr detailed report per Rules notified 13 Nov 2025) fully enforceable ~May 2027 = closing runway, never claim current enforcement; agentic SOC is a recognized Gartner category with the India layer empty.

## 2.4 Core differentiation (POST-VERIFICATION VERSION — use this, not the old Copilot-absolute)
> "Global AI-SOCs like Microsoft Security Copilot don't speak India's regulatory language — none drafts a CERT-In or DPDP report. India's compliance tools make humans type incident facts into forms. CITINEL is the only system where the investigation itself writes the draft — detection to regulator-ready report, one pipeline."

**Three headline features (+1 roadmap):**
1. **Compliance-clock module** — CERT-In/DPDP forms auto-drafted from the live incident record (~70–80% CERT-In fields machine-draftable); human sign-off mandatory by design (no filing API exists — CERT-In channel is email/fax/PDF, form not even mandatory)
2. **Injection-hardened pipeline** with live attack-then-defense demo (poisoned log hijacks a naive agent, fails against CITINEL; attack peer-published; ~one vendor claims a defense)
3. **Readable autonomy** — per-action-class OPA policy + Shadow→Assist→Autonomous dial + blast-radius rings (CrowdStrike-outage lesson) vs incumbents' black-box "bounded autonomy"
4. (roadmap line) Portable open Sigma-rule + playbook flywheel from every resolved incident — anti-lock-in

## 2.8 Armed answers (the four post-lock fixes + hardest Q&A digest)
- **Autonomy tension:** "Autonomy is a dial, not a switch — fully autonomous on reversible actions, policy-gated on consequential ones. That's what makes autonomy deployable."
- **Demo-data mismatch:** "Co-op banks run the same Windows/AD/network stack our demo telemetry uses; core-banking connectors are roadmap."
- **Copilot comparison:** use the §2.4 narrowed line only (never claim Copilot is 'not available in Indian government clouds').
- **"Regulator won't accept a machine report":** correct — human sign-off is mandatory, audit trail proves detect-time and report-time; we draft, we never file.
- **"Replacing analysts?":** India is short 790,000 professionals; CITINEL does Tier-1 toil so scarce humans do judgment.
- **Wrong-action fear:** consequential actions can't run without approval; isolations carry rollback; blast-radius rings cap exposure; staged rollout is designed in (CrowdStrike lesson).
- **Hallucination:** every verdict must cite the exact log line (Citations); structured outputs validate machine paths; eval harness measures; humans gate consequences.
- **Injection:** peer-published attack, demoed live; logs are data never instructions; detectors + egress allow-list; poisoned string appears visibly flagged inside the draft.
- **FP rate:** industry runs 46–80% by survey; we target <10% and publish our measured rate on labeled data rather than claim it.
