# Startuped.ai module exports

Drop the real outputs here, one file per module, named for the criterion:

    idea-validation.*      market-research.*     product-positioning.*
    gtm-planning.*         launch-strategy.*

Screenshots (`.png`) or exported text (`.md`) both work. Versioning them with
the code is the point: an export sitting in a Downloads folder is not evidence
a judge can check, and a screenshot in a slide deck cannot be traced back to
the run that produced it.

Then replace the matching `[AWAITING YOUR EXPORT]` slot in
`../../STARTUPED-QUALIFICATION.md` with the real output.
